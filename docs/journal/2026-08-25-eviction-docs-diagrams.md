# Eviction strategy guide with source-derived diagrams

## Goal

Document all eight segcache eviction policies at mechanism level — not a
restatement of the `Policy` enum docs, but the shared substrate (TTL-bucket
chains, `expire()`-first, `can_evict` excluding the Live tail and pinned
segments) and the three genuinely different shapes: whole-segment selection,
merge's prune-and-compact chain walk, and S3-FIFO's admission/ghost/CLOCK
flow. Figures must be derived from source with fail-loud claims, in this
repo's own toolchain.

## What happened

- `docs/eviction.md`: roster table, invariants, and three figures with full
  text equivalents; `docs/segcache.md`'s eviction section links to it.
- Figures are generated by `crates/segcache/examples/eviction_diagrams.rs`
  (`cargo run -p segcache --example eviction_diagrams`), following the
  `ziplist --example block_anatomy` precedent. The generator asserts 22
  exact source claims plus one ordering claim (admission-pool eviction
  precedes main) against `crates/segcache/src` and aborts on drift;
  bounds-checks all 193 drawn elements into their viewBoxes; and stamps each
  SVG with the last commit touching `crates/segcache/src` (scoped so
  docs-only commits cannot stale the stamp).
- The generator was first built in Python for iteration speed, then
  rewritten in Rust before landing: the repo has no Python toolchain, and a
  contributor who cannot run the generator has a hand-maintained diagram in
  practice. Rendered output is equivalent (same claims, same 193 elements,
  same geometry).
- Three render-verified fix rounds during figure development: non-ASCII
  glyphs (`≤ → ∧`) rendered as tofu under font fallback; callout arrows
  pierced labels; converging copy-lines grazed box titles. Geometry bounds
  checks caught none of these — only rasterize-and-look did.

## Decisions

- This PR introduces `docs/diagrams/` (and this entry `docs/journal/`) on
  main before the in-flight ziplist branch lands its own copies of the
  directory READMEs. To avoid guaranteed merge conflicts with that branch,
  neither README is added here; provenance lives in `eviction.md` and this
  entry, and index rows can be added when the branches converge.
- Committed SVGs are self-contained (explicit ink, white ground) rather
  than `currentColor`-themed: markdown viewers render them as images, where
  `currentColor` resolves to black regardless of theme.
- Freshness is manual. A CI regenerate-and-diff check is the natural
  follow-up: emission is deterministic (integer-formatted geometry, fixed
  order, no external renderer).

## Outcome

Lands as PR pelikan-io/cache-rs#87 (`docs/eviction-diagrams`). Claims hold
at `073cce5`.

## Skill Feedback

### architecture-diagram (beta)

- **Confirmation** — "Build the generator in the project's native
  toolchain — no new contributor dependency" was violated first (Python for
  iteration speed) and the violation cost a full rewrite the same week the
  figures landed. The rule held; the shortcut did not.
- **Confirmation** — "Verify the rendering, not the source": bounds
  assertions passed on all three figures while rasterization exposed three
  rounds of real label/arrow collisions. The perceptual pass is not
  optional.
- **Friction** — The dead-ends list warns only about Unicode *circled
  digits* dying in font fallback. The failing class is wider: any
  non-ASCII symbol in SVG text (`≤`, `→`, `∧`) hit tofu under the fallback
  font and had to be rediscovered and replaced with ASCII. The dead-end
  should generalize to "non-ASCII symbols in SVG text".
- **Confirmation** — Single-use mode as documented (fail-loud claims,
  commit stamp, no charter) ported unchanged across two implementation
  languages; the claim table was the only part that needed zero rework.
